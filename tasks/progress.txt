## Codebase Patterns
- Chunk API endpoint: GET /api/chunks/{id} returns ChunkDetails with content and page_start/page_end
- PDFReader uses highlightChunkId prop to highlight content
- EPUBReader uses highlightAnchor prop for navigation
- ReactReader from 'react-reader' provides EPUB rendering with continuous scroll support
- Use epubOptions: { flow: 'scrolled', manager: 'continuous', spread: 'none' } for continuous scroll
- Location in ReactReader can be CFI string, chapter href, or percentage (0-1)
- ThreeColumnLayout: Left flex-[4] (40%), Center flex-[5] (50%), Right 280px fixed
- Center panel expands to flex-[9] when right panel is hidden (maintains 40:60 ratio)
- Root container should use `h-screen overflow-hidden` to prevent page-level scroll
- Each panel has `overflow-hidden` container with internal `overflow-auto` scroll areas
- Tab navigation uses `flex-shrink-0` to remain fixed during content scroll

# PRD: 智能阅读概念图谱系统 - 评估验证系统

## 1. 概述

本系统旨在为"智能阅读概念图谱系统"建立一套自动化的评估验证框架，通过实际运行测试用例验证系统的核心功能完整性，并在发现问题时记录问题、迭代修复，最终确保系统稳定可靠。

**核心价值**：
- 通过端到端测试验证用户可见功能的正确性
- 通过 API 契约测试确保前后端集成的健壮性
- 通过 UI 自动化验证界面交互的可用性
- 建立可重复的评估流程，支持持续迭代优化

---

## 2. 目标

- [ ] 建立测试数据准备机制：通过 API 上传样本书籍到系统
- [ ] 实现端到端功能测试：验证上传→解析→概念提取→图谱生成全流程
- [ ] 实现 API 契约测试：验证所有 REST API 接口的正确性
- [ ] 实现 UI 自动化验证：验证关键界面组件的渲染和交互
- [ ] 建立评估报告生成机制：每次评估生成结构化报告到 `tasks/` 目录

- [ ] 支持迭代评估：修复后能重新运行评估验证修复效果

## 4. 功能需求

### FR-1: 测试数据准备
- FR-1.1: 扫描 `sample_books/` 目录获取可用的测试书籍文件
- FR-1.2: 通过 `/api/books/upload` 接口上传书籍（multipart/form-data 格式）
- FR-1.3: 上传时提供 title 和 author 元数据
- FR-1.4: 返回并记录每个书籍的 `book_id`
- FR-1.5: 验证上传后的书籍可通过 `/api/books` 查询到

### FR-2: 端到端测试执行器
- FR-2.1: 按顺序执行：上传 → 解析 → 提取 → 图谱获取
- FR-2.2: 每个步骤验证 HTTP 响应状态码为 200
- FR-2.3: 每个步骤验证响应数据结构符合预期
- FR-2.4: 任何一个步骤失败则记录错误并终止流程
- FR-2.5: 支持对指定书籍 ID 执行全流程测试

### FR-3: API 测试套件
- FR-3.1: 实现所有 GET 接口的测试
- FR-3.2: 实现所有 POST 接口的测试
- FR-3.3: 实现 PUT/DELETE 接口的测试
- FR-3.4: 测试错误情况：无效 ID、不存在的资源、格式错误请求
- FR-3.5: 每个测试用例记录：通过/失败、响应时间、错误详情

### FR-4: UI 自动化验证
- FR-4.1: 使用 dev-browser skill 或类似工具启动浏览器
- FR-4.2: 访问前端页面并验证基本加载
- FR-4.3: 验证书籍列表组件渲染
- FR-4.4: 验证 PDF/EPUB 阅读器组件挂载
- FR-4.5: 验证图谱可视化组件渲染
- FR-4.6: 捕获控制台错误（Error 级别）并记录

### FR-5: 评估报告生成器
- FR-5.1: 生成 Markdown 格式的评估报告
- FR-5.2: 报告文件命名：`tasks/evaluation-report-YYYY-MM-DD.md`
- FR-5.3: 报告包含执行摘要（总测试数、通过数、失败数）
- FR-5.4: 报告包含每个测试用例的详细结果
- FR-5.5: 报告包含发现的问题列表（按严重程度分组）
- FR-5.6: 报告包含与历史评估的对比趋势（可选）

### FR-6: 服务生命周期管理
- FR-6.1: 评估前启动服务（调用 `start.sh` 或直接启动后端/前端）
- FR-6.2: 等待服务就绪（轮询 `/api/health` 确认）
- FR-6.3: 评估完成后可选停止服务
- FR-6.4: 支持在服务已运行时跳过启动步骤
- FR-6.5: 服务启动失败时提供清晰的错误信息

### FR-7: 迭代评估支持
- FR-7.1: 记录上次评估发现的问题
- FR-7.2: 识别问题状态变更（新增/已解决/持续存在）
- FR-7.3: 可选择性只运行之前失败的测试用例
- FR-7.4: 生成问题解决率趋势统计

## 5. 非目标（范围外）

- **不包含性能压力测试**：本评估聚焦功能正确性，不做并发/负载测试
- **不包含安全渗透测试**：不测试 SQL 注入、XSS 等安全漏洞
- **不包含自动化 UI 测试框架搭建**：优先使用 dev-browser skill 进行手动浏览器验证
- **不包含测试数据清理机制**：每次评估使用新的书籍上传，不清理历史数据
- **不包含 CI/CD 集成**：评估流程可通过脚本手动触发

### API 端点参考
```
GET  /api/health                  - 健康检查
GET  /api/settings/language       - 获取语言设置
PUT  /api/settings/language        - 更新语言设置
POST /api/books/upload            - 上传书籍
GET  /api/books                    - 列出书籍
GET  /api/books/{id}               - 获取书籍详情
DELETE /api/books/{id}             - 删除书籍
POST /api/books/{id}/parse         - 解析书籍
GET  /api/books/{id}/chunks        - 获取章节
GET  /api/books/{id}/graph         - 获取图谱
POST /api/books/{id}/extract       - 提取概念
GET  /api/graph/global             - 获取全局图谱
GET  /api/chunks/{id}              - 获取章节详情
GET  /api/nodes/{id}               - 获取节点详情
```

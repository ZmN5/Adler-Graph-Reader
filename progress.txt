## 2026-03-28 - US-007 - Fix EPUB Reader loading issue
- Fixed EPUB Reader cannot load EPUB files by passing ArrayBuffer directly to epubjs instead of blob URL
- Root cause: blob URLs don't support relative URL resolution for internal EPUB resources (chapters, images, CSS)
- Files changed: frontend/src/components/EPUBReader.tsx
- **Learnings for future iterations:**
  - epubjs with blob URL fails because it extracts relative URLs from EPUB content that can't be resolved against a blob URL
  - Solution: use `fetch('/api/books/${bookId}/file').then(r => r.arrayBuffer())` and pass to `ePub(arrayBuffer)`
  - Don't need to call URL.revokeObjectURL when using ArrayBuffer approach

## Codebase Patterns
- Use `cn()` utility from `@/lib/utils` for merging Tailwind classes
- Modal/dialog components should be placed at the end of the return JSX, inside the root element
- Use `useCallback` for event handlers that are passed to child components to avoid unnecessary re-renders
- Book list state uses `BookSummary` type from `@/lib/api-client`
- Custom dropdowns need `useRef` for the container and `useEffect` for click-outside handling
- Dropdown menus should use `absolute positioning` with `z-50` and `shadow-lg` for proper layering

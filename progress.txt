## Codebase Patterns
- Use `&*pool` when passing `State<SqlitePool>` from Axum extractors to sqlx query executors (State wraps the pool, needs deref to get `&Pool` which implements Executor)
- When using Axum Router with `.with_state(pool)`, the pool is moved into the router state and accessed via `axum::extract::State<T>`
- Rust: Import routing::{get, put} for both GET and PUT route handlers
- In Axum handlers with multiple extractors, State must come before other extractors (e.g., State<SqlitePool> first, then Multipart)
- Use custom AppError enum implementing IntoResponse for consistent error handling across handlers

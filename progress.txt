## Testing Workflow
- Use browser-use to automate testing of the product
- Test sample books from sample_books/ directory
- Each round: test -> document issues -> fix issues -> verify
- Terminate after 10 rounds OR 3 consecutive rounds with no new issues

## Codebase Patterns
- New books show "Parse" button, parsed books show "Extract" button
- Parse/Extract buttons disable when work is in progress (shows as disabled=true in browser-use state)
- API `/api/books` returns `total_pages: 1` even when UI shows correct page count - this is a known bug
- browser-use CLI persists between commands - no need to reopen browser
- For browser-use python: use simple expressions, avoid chaining with semicolons

## Issue Severity Definitions
- P0: Core functionality completely broken
- P1: Core functionality severely impaired
- P2: Feature broken but has workaround
- P3: UI/UX issue

## 2026-03-29 - US-001: Fix EPUB Reader Rendering
- **Bug**: EPUBReader had a chicken-and-egg problem where the viewer div required `rendition` to be non-null to render, but `rendition` was only set inside an effect that required the viewer div to exist first.
- **Fix**: Restructured EPUBReader so the viewer div renders whenever `book` is loaded (even if `rendition` hasn't been set yet). Added a spinner inside the viewer until rendition is initialized.
- **Files changed**: `frontend/src/components/EPUBReader.tsx`
- **Learnings for future iterations:**
  - React effects run AFTER the DOM is painted, so refs should be available if the element is rendered
  - When using refs with conditional rendering, ensure the element exists before the effect runs
  - If an effect depends on a DOM element being rendered, that element must not depend on state set inside the effect

## 2026-03-29 - US-002: Fix PDF Container Overflow
- **Bug**: PDF canvas overflowed container horizontally and didn't fit vertically
- **Fix**: Changed `overflow-auto` to `overflow-hidden` on canvas wrapper, added `max-w-full h-auto` to canvas. Captured container dimensions synchronously before async render to avoid TypeScript null errors, added height-based scale calculation.
- **Files changed**: `frontend/src/components/PDFReader.tsx`
- **Browser verification**: Confirmed no horizontal scrollbar, PDF fits within container bounds
- **Learnings for future iterations:**
  - Container ref dimensions should be captured synchronously before async operations (avoid TypeScript null check issues in effects)
  - Canvas scaling should consider both width AND height constraints to prevent overflow
  - Use `overflow-hidden` instead of `overflow-auto` on canvas container to prevent scrollbars

## 2026-03-29 - US-004: EPUB Citation Navigation
- **Bug**: For EPUB books, citation clicks passed `highlightChunkId` (UUID) as `highlightAnchor`, but epubjs `rendition.display()` requires CFI or href strings - UUIDs cause silent failures
- **Fix**: Pass `highlightAnchor={null}` for EPUB so citation navigation uses percentage-based navigation via `pageNumber` prop instead (which is the correct approach for EPUB)
- **Files changed**: `frontend/src/App.tsx`
- **Browser verification**: Basic EPUB navigation works (chapter dropdown, Next/Previous buttons). EPUB citation navigation requires concept extraction (LLM processing) which takes too long for automated testing.
- **Learnings for future iterations:**
  - For EPUB citation navigation, epubjs percentage-based navigation via `rendition.display(percentage)` is the correct approach (EPUBs don't have fixed pages)
  - `highlightChunkId` is a database UUID - not usable by epubjs directly
  - `pageNumber` prop in EPUBReader represents chapter number (page_start from chunks table) which is used to calculate percentage
  - `totalPages` from `selectedBook.total_pages` is used to normalize chapter number to percentage

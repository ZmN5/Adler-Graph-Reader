### **Learnings for future iterations:**
- epub.js `renderTo()` creates an iframe, but `display()` must succeed for content to actually render
- Dead code in React components can cause confusing behavior - always ensure error/loading states are handled consistently
- When using flex layout with `flex-direction: column`, child `flex-1` elements may need `min-h-0` to properly shrink/grow
- The initial `isRendering` state should be `true` since rendition initialization begins immediately on mount

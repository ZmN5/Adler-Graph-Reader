## Codebase Patterns
- SQLite doesn't support `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` syntax
- Use `PRAGMA table_info('table_name')` to check column existence in SQLite
- Pattern: `SELECT COUNT(*) > 0 FROM pragma_table_info('table') WHERE name = 'column'`
- sqlx `query_scalar` can fetch boolean results directly
- Backend database is at `backend/data/reader.db`, not project root

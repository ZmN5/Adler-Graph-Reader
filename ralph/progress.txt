## Codebase Patterns
- Backend runs on port 8080, frontend on port 3000
- Health endpoint: GET /api/health returns {"status": "ok"}
- Backend typecheck: cargo check
- Frontend typecheck: npm run typecheck
- Use scripts/run-evaluation.sh as evaluation entry point (not start.sh)
- DELETE /api/books/{id} returns {"deleted": true} on success
- Language setting values: 'zh' or 'en' (lowercase only), invalid values return HTTP 400
- curl -s -w "\n%{http_code}" captures both response body and HTTP status code
